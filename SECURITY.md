# Security Policy / 安全政策

## Supported Versions / 支持的版本

We support security updates for **2.0.1.60** and **2.0.1.60** versions. Any versions below **2.0.1.60** will no longer receive security updates. / 我们为 **2.0.1.60** 和 **2.0.1.60** 以上的版本提供安全更新。低于 **2.0.1.60** 的版本将不再接收安全更新。

## Reporting a Vulnerability / 报告漏洞

To report a security vulnerability, please email us at **wsp001112@gmail.com** or open a private issue on GitHub (via **Security Advisories** section). / 要报告安全漏洞，请通过电子邮件 **wsp001112@gmail.com** 联系我们，或在 GitHub 上的 **Security Advisories** 部分提交私密问题。

### Expected Response Time / 预计响应时间:
We strive to acknowledge all reports within 48 hours and provide an initial response with a plan of action. / 我们致力于在 48 小时内确认所有报告，并提供初步的行动计划。

### Vulnerability Review / 漏洞审查:
Once a vulnerability is reported, we will evaluate it and determine whether it is accepted. If the vulnerability is accepted, we will: / 一旦报告漏洞，我们将对其进行评估并决定是否接受。如果漏洞被接受，我们将：
- Patch the issue in a timely manner. / 及时修复问题。
- Notify all users of the affected versions. / 通知所有受影响版本的用户。
If the vulnerability is declined, we will provide an explanation and may suggest alternate solutions. / 如果漏洞被拒绝，我们将提供解释并可能建议替代解决方案。
